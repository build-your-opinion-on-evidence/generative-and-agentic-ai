# Generative & Agentic AI

Part of [Build Your Opinion on Evidence](https://github.com/build-your-opinion-on-evidence/evidence-hub), an evidence-driven research and engineering series.

Generative models, LLMs, retrieval, agent orchestration, memory, and tool use.

## Projects

Projects live under `projects/`, with one directory per research project. No completed projects have been added yet.

Start by copying [the project template](projects/_template/README.md) into `projects/<project-id>-<short-name>/`.

## Project contents

| Path | Purpose |
| --- | --- |
| `README.md` | Research question, scope, setup, and conclusions |
| `references/` | Source links, citations, and implementation notes |
| `src/` | Project code |
| `experiments/` | Configurations and reproducible run commands |
| `results/` | Measured results and supporting artifacts |
| `docs/` | Architecture, dataflow, and detailed explanations |
| `media/` | Published articles, videos, and posts |

Create these directories as the project gains content. Each project manages its own dependencies and environment.

## Evidence standards

Follow the [shared methodology](https://github.com/build-your-opinion-on-evidence/evidence-hub/blob/main/METHODOLOGY.md). Record deviations from source papers, report unsuccessful runs, and link conclusions to saved evidence.

Register published projects in the [central catalog](https://github.com/build-your-opinion-on-evidence/evidence-hub/blob/main/PROJECTS.md).
